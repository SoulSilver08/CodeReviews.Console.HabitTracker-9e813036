## Project Developing Overview
At the begginning of this project i was kinda lost because, even when i had used SQL in other projects, i had never used ADO.NET, plus the fact that when i installed the NuGet package i wrongli installed the ADO.NET Core package instead of the normal one, just that was like 1 hour of troubleshooting.

after fixing that problem it was time to remember the SQL Commands (nothing that W3 Schools can't help with though).

At the end once i solved all the problems with ADO.NET and remembering the SQL Commands everything went smoothly, or well almost everything.
